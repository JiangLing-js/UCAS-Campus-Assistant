# UCAS Campus Assistant · 国科大校园助手

面向 Windows 的本地校园工作台，将课表、通知、讲座、活动、待办和邮件标题整理到同一界面。支持 DeepSeek 对话、stdio MCP 和 Chrome 页面同步。

这是个人使用的非官方工具。

## 功能

| 模块 | 能力 |
| --- | --- |
| 对话与 MCP | DeepSeek 工具调用、18 个 MCP 工具、对话记录 |
| 校园信息 | 一键自动进入九类校园来源，显示逐项进度，支持失败重试与取消 |
| 待办与提醒 | 文字识别 DDL、批量导入、事项编辑、延后提醒、后台通知、ICS 导出 |
| 选课规划 | XLSX / XLS / CSV / JSON 导入、手动添加、备选方案、学分合计与时间冲突检查 |
| 邮箱 | 浏览器同步邮件标题；可选只读 IMAP，最近 100 封信封信息 |
| 登录 | 通过本机加密凭据填写 SEP / 邮箱登录页，验证步骤留在官方页面完成 |
| 显示 | 对话工作台、90%–160% 字体大小调整 |

## 运行

需要 Windows、Node.js 24 或以上、Chrome。

```text
npm ci
npm start
```

打开 [本地工作台](http://127.0.0.1:3210/)。也可以双击 `start.cmd` 后台启动，双击 `stop.cmd` 停止。

在「连接与设置」中填写自己的 DeepSeek API Key。无需密钥即可使用本地待办、课表查看、课程规划等功能。已有凭据留空保存会保留原值。

数据保存在项目下的 `data/`，账号密码与密钥使用 Windows DPAPI CurrentUser 加密。

## Chrome 校园桥接

1. 打开 Chrome 扩展管理页，开启开发者模式。
2. 选择「加载已解压的扩展程序」，选择本项目的 `extension` 文件夹。
3. 刷新工作台，正常登录 SEP 和邮箱，保留已登录的邮箱标签页。
4. 点击顶部「一键同步全部」，首次会自动配对本机桥接。也可以在对话中要求刷新全部来源。

升级已有扩展时，在扩展管理页重新加载「国科大校园桥接」，确认版本 **0.5.2**，并刷新工作台。扩展弹窗可开启每 15 分钟自动进入各系统同步，也保留手动连接码配对与仅同步已打开页面的选项。

自动同步包括 SEP 通知、常用系统、本周课表、科学前沿讲座、网络课程列表、团委二课、邮箱收件箱、校园网用量和校园新闻。程序复用已有登录，在临时标签页中采集；成功后关闭自己创建的标签页，验证或失败页面保留。「同步记录」显示每个来源的结果，可重试未完成项目或取消任务。重复请求会合并缺少的来源，任务中断后可继续。

保持 Chrome 和本地服务运行。后台提醒需在扩展弹窗勾选「工作台关闭后也提醒」，允许通知并保存连接。验证码、额外账号选择与独立系统的权限仍由用户在官方页面处理。

## 一键登录与邮箱

在设置页保存 SEP 或邮箱账号密码，再点击「保存并登录」，或使用设置 / 校园服务页的「一键登录」按钮。

邮箱自动同步复用已登录标签页的当前 Coremail 会话，在独立临时页打开收件箱。会话地址仅在扩展内存中使用，不保存到数据库、同步结果或模型上下文。同步邮件不会自动开启模型读取邮件的权限；邮件对话查询仍需在本地设置单独启用。

## 课程导入与提醒

课程文件最多 8 MB、10000 门，先预览解析结果再保存。支持多工作表、常见中文表头、单双周与同课多行安排；未知时间会提示待核对。课程方案保存在本机，不向学校提交选退课。

DDL 和提醒可手动添加或通过对话创建。在「待办与 DDL」点击「识别 DDL」，粘贴作业或通知即可在本机识别，修改预览后批量保存。通知、新闻、笔记和活动卡片也提供识别入口。相对日期按所选参考日期解释；年份、时刻或多个日期需要核对时会提示，缺少明确时刻的候选默认不选中。相同标题、时间、来源的重复导入会跳过已有事项。

本地事项可编辑标题、时间、地点及提醒设置。到期通知可以延后 10 分钟、30 分钟或 1 小时再次提醒，原截止时间不变；完成或归档事项后不再发出排队的延后提醒。

到期检查需要本地服务运行。页面打开并允许通知时可以接收桌面提醒；启用校园桥接后台提醒后，即使关闭工作台也可每分钟检查一次，但仍需要 Chrome 运行。退出或休眠期间不会弹窗，恢复后最多补查过去 24 小时内的未读提醒。页面与扩展共用持久送达记录以减少重复；发送成功但确认失败时仍可能重试。

DDL 识别仅处理粘贴或已同步的文字，不调用模型 API，不会自动遍历所有课程作业。

## MCP

在工作台设置页复制适合当前机器的完整配置，或参考 [mcp-config.example.json](mcp-config.example.json)。将 `ABSOLUTE_PROJECT_PATH` 替换成项目的绝对路径，保存到自己的 MCP 客户端设置中。

新增 `extract_deadlines` 返回候选时间与原文证据，确认后可使用 `create_item` 保存；`update_item` 修改已有事项。提取本身不创建事项，也不提交作业或报名。

`sync_campus` 启动全部或指定来源同步，`get_sync_status` 返回逐项结果，`cancel_sync` 取消未完成项目。`sync_source` 同样使用浏览器同步任务。DeepSeek 与 MCP 共用持久任务队列，桥接负责执行浏览器操作；任务排队或执行中不代表同步成功。MCP 和工作台应指向同一数据目录。

## 检查与隐私

运行 `npm test` 检查解析、登录、同步队列、提醒、HTTP 和真实 stdio MCP。公开发布前运行 `npm run check:public`，暂存后运行 `npm run check:staged`。

仓库只包含通用代码、文档和虚构测试数据。账号密码、API Key、Cookie、邮箱与聊天记录、个人课表和本机连接配置保留在本机。详见 [发布与隐私](docs/publishing.md) 和 [已知限制](docs/known-limitations.md)。

## 环境变量

| 名称 | 用途 |
| --- | --- |
| `PORT` | 工作台端口，默认 3210；更改后同步修改扩展本地地址 |
| `UCAS_DATA_DIR` | 自定义本机数据目录；不要放入 Git 跟踪范围 |
| `DEEPSEEK_API_KEY` | 可选，替代在保险箱中保存的 API Key |
