# 发布与隐私

公开仓库只提交通用源代码、说明和虚构测试数据。每个使用者自行在本机配置账号与密钥，首次运行创建自己的空数据库和连接码。

发布前运行 `npm run check:public`，暂存后再运行 `npm run check:staged`，检查实际提交内容。检查覆盖敏感文件类型、常见令牌、非示例邮箱、本机路径与会话参数；不打印匹配值。数据库、加密凭据、邮件、聊天记录、课表快照与本机 MCP 配置都不应提交。

图片默认禁止发布，仅允许经过人工查看并固定 SHA-256 的通用通知图标 `extension/icon.png`。替换图标后必须重新审核，不能通过开放全部图片类型来绕过检查。自动扫描不能替代人工审阅差异。
