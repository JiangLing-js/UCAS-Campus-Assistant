# 已知限制

- SEP 自动登录仍在适配验证中；加载时序、页面跳转和学校验证策略可能导致自动登录中断。失败时查看工作台提示和官方页面，必要时手动登录。
- 账号密码不绕过验证码、二次验证、校园网络要求或账号权限。程序不自动退出已有会话或切换账号。
- 一键课表同步采集默认打开的当前周，没有推断整个学期。其他周次可在官方课表切换后使用「同步已打开页面」补充；网络课程同步列表，不遍历每门课的作业页面。
- 不自动提取所有课程作业的截止日期，不代替选课、报名、交作业、校园网缴费等提交操作。
- 选课方案只检查已知星期、节次和周次的交集，不代表实时余量、考试安排或满足培养要求。
- 邮件快照只有收件箱当前列表页，不采集正文和附件。保留已登录邮箱标签页供自动同步复用会话；IMAP 需账号启用相关服务，网页登录密码与客户端专用密码可能不同。
- 一键同步需要 Chrome、校园桥接 0.5.2 及本地服务运行。动态网页可能无法仅靠 Cookie 同步，网站改版后可能需要调整导航和解析器。登录失效或多账号选择等情况会保留官方页面等待用户处理。
- Windows DPAPI 凭据不能直接迁移到其他 Windows 用户。程序默认仅监听本机回环地址。
- 数据库中的校园内容、邮件标题和对话记录为本机明文数据，应与加密保险箱一起保持在 Git 跟踪范围之外。
- 运行时已获用户许可的相关对话与工具查询结果可能发送给 DeepSeek。邮件标题查询默认关闭。

自动测试覆盖解析、同步、访问控制、凭据领取和登录页面适配器；模拟测试通过不代表真实学校网站的所有流程都已验证。
